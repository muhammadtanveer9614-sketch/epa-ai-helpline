# EPA Helpline 1373 - AI Voice & Workflow Automation Engine

An autonomous, enterprise-grade AI helpline system designed to streamline citizen complaint management for government environmental protection departments.

## 🚀 Key Features
- **24/7 Voice Reception:** Powered by Vapi AI & ElevenLabs for natural, human-like local language interaction.
- **Smart Data Parsing:** OpenAI API automatically extracts citizen names, geographic locations, and complaint details from live call transcripts.
- **Automated Data Routing:** Seamlessly logs entries into Google Sheets and triggers instant alerts to respective District Officers (DO).
- **Self-Hosted Security:** Built on n8n to ensure data privacy and zero recurring SaaS bloat.

## ⚙️ Tech Stack
- **Automation Engine:** n8n
- **AI / LLM:** OpenAI (GPT-4o-mini)
- **Voice & Telephony:** Vapi AI / ElevenLabs
- **Database / Logging:** Google Sheets / Google Workspace
